# Screenshots Folder

Store your route and terminal execution screenshots in this directory with the following filenames:

1. `home_route.png` - Browser/Postman screenshot of `GET http://localhost:3000/` returning `200 OK` and "Welcome to the Node.js and Express.js Server! (Lab 1)".
2. `about_route.png` - Browser/Postman screenshot of `GET http://localhost:3000/about` returning `200 OK` with JSON (name, registration number, section).
3. `time_route.png` - Browser/Postman screenshot of `GET http://localhost:3000/time` returning `200 OK` with current ISO and formatted time.
4. `not_found_route.png` - Browser/Postman screenshot of unknown route e.g. `GET http://localhost:3000/invalid` returning `404 Not Found`.
5. `terminal_output.png` - Screenshot of terminal showing `npm start` and the console request logs.
